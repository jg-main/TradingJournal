# Mode: Dashboard Workstation

Use for account overview, live positions, risk, performance, and analytical dashboards.

Core rules:

- Desktop-only or desktop-first.
- One unified grid.
- Grouped metrics, not one card per number.
- Open Positions and Risk above the fold.
- Current risk before secondary analytics.
- Shared data layer.
- One live polling lifecycle.
- Live and historical refresh separated.
- Explicit customization mode.
- Saved views.
- Screenshot review at 1440 × 900.

Read `references/dashboard-workstation.md`.
