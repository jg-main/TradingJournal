# Mode: Visual Critique

Use when an implementation exists and needs review.

Do not begin by rewriting code.

1. Render at the target viewport.
2. Use realistic data.
3. Identify the primary decision.
4. Rank defects by impact.
5. Separate structural, workflow, hierarchy, density, rendering, and cosmetic defects.
6. Recommend the smallest correction that addresses the root cause.
7. Fix only the highest-impact defects in the next pass.
8. Capture before and after evidence.

Do not praise implementation completeness when the visual result fails.
