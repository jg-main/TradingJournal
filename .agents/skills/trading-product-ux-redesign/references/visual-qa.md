# Visual QA

Review relevant populated, sparse, empty, loading, error, stale-data, missing-data, validation-failure, destructive-action, keyboard-focus, narrow desktop, and large-monitor states.

Reject when:

- The main action is unclear.
- Important state is below unrelated content.
- Large areas contain little information.
- The screen looks like a generic template.
- Related values are far apart.
- Duplicate controls compete.
- A chart or table does not fit its container.
- Realistic data causes clipping or uncontrolled page growth.
- Color is the only carrier of meaning.
- Critical warnings look like ordinary metadata.
- Normal mode exposes editing affordances.
- Empty states dominate the page.
- Tests pass but visible acceptance fails.

Record viewport, user goal, first three-second impression, above-the-fold contents, scan path, largest wasted area, most dangerous ambiguity, and highest-impact correction.
