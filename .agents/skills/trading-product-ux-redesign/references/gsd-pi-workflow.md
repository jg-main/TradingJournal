# GSD-Pi Workflow for UX Redesign

## Milestone context template

```markdown
# Milestone: <name>

## User problem
## Operating context
## Scope
## Out of scope
## Selected UX mode
## Domain invariants
## Reuse boundary
## Non-reuse boundary
## Target routes
## Core journeys
## Visual direction
## Evidence plan
## Coexistence or cutover strategy
## Acceptance criteria
```

## Slice context template

```markdown
# Slice: <name>

## User-visible outcome
## Why this slice is vertical
## Inputs and dependencies
## Routes/components affected
## Domain operations used
## UX states
## Browser evidence required
## Tests required
## Acceptance criteria
## Deferred work
```

For every visual slice, preserve viewport, seed state, screenshot paths, demonstrated actions, observed defects, acceptance results, unmet criteria, and next-slice reassessment.

Prefer `decompose-into-slices` for broad redesigns.
